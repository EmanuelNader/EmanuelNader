# HI I'm Emanuel Nader

Math-CS @ UC San Diego, class of 2028. Currently a Technical Program Manager intern at Tesla on Chassis Controls.

I like problems where the software has to touch something real: a vehicle fleet, an IMU on someone's wrist, a room full of people trying to coordinate a night out.

---

### What I'm building

**[trackbench](https://github.com/EmanuelNader/trackbench)** — C++ multi-object tracker (EKF + Hungarian association) benchmarked on nuScenes. Cut identity switches by 53% against the baseline.
`C++` `Eigen` `nuScenes`

**ShotClock** ![private](https://img.shields.io/badge/private-6e7681?style=flat-square) — React Native app for shared night-out timelines. Group state sync, per-session theming, dark-only design system.
`React Native` `Expo` `TypeScript`

**Steady** ![private](https://img.shields.io/badge/private-6e7681?style=flat-square) — Wrist-worn BAC estimator. Custom firmware on a XIAO nRF52840 Sense streaming IMU data over BLE to a paired mobile app.
`C` `Zephyr` `BLE` `React Native`

**[Nutribase](https://github.com/EmanuelNader/nutribase)** — Smart fridge tracker. Custom ESP32 firmware streaming load-cell weight data at 10+ payloads/sec over MQTT into a MERN backend with role-based auth. Ran in a dorm for 10 weeks.
`C++` `ESP32` `MQTT` `MongoDB` `Express` `React`

*Private repos are in active development*
